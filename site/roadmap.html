Proposed direction / SVG tools

Draw it. Refine it.
Make it move.

Vector drawing and editing within Pixel Perfect’s workspace. Pen leads the discussion; the sequence below is a starting proposal.

  1. 01

    The drawing foundation

    Proposed first

    Author and edit real paths in SVG Animation.

    Pen tool & cursor

    Use the Pen tool’s pen icon as the canvas cursor. Place corner anchors, drag Bézier handles, create open or closed paths, and continue an existing path.

    Direct Selection & anchor editing

    Select individual nodes and handles. Add, remove, smooth, split, and join paths without creating an animation just to edit the drawing.

    Everyday canvas editing

    Move artwork by dragging its body; select, duplicate, group, and organize several objects. Give SVG import a clear Add or Replace choice.

    A movable Pen toolbar

    Selecting Pen opens a toolbar floating on the right, styled like the bottom floating toolbar. Move it around the workspace and access the Pen/Pencil tool set, stroke color, and fill color together.

    The floating toolbar and right inspector edit the same stroke and fill. The proposed tool set includes Pen, Direct Selection, add/delete/convert anchors, split/join paths, Pencil, and smoothing. See the Pen workspace specification for behavior and open scope choices.

  2. 02

    Precision & construction

    Proposed next

    Turn simple shapes into finished artwork.

    Alignment & snapping

    Align and distribute SVG objects; snap to useful geometry and guides. Build on the controls already available in Design.

    Pathfinder & Shape Builder

    Unite, subtract, intersect, and exclude shapes. Discuss Boolean operations first, followed by interactive region selection.

    Clipping masks & compound paths

    Create and edit clipped artwork and shapes with holes. Preserve the result when saving, importing, and exporting.

    Depends on path editing and multiple-object selection. Imported masks already render in SVG Animation; authoring them is the proposed work.

  3. 03

    More expressive artwork

    Proposed later

    Add personality without leaving the canvas.

    Pencil & Brush

    Pencil and smoothing belong in the proposed floating tool set. Discuss whether they ship with Pen, and scope pressure, variable-width strokes, and brush presets separately.

    Text on a path

    Place editable text along a curve, then adjust its offset, direction, and spacing.

    Gradient tools

    Edit gradient stops and direction on the SVG canvas. Design already has gradient tools; gradient animation needs its own scope decision.

    Depends on stable path and paint editing, with font and export behavior agreed before implementation.

  4. 04

    Connect & deliver

    Explore

    Carry work between tools and into a finished project.

    Design ↔ SVG Animation

    Send selected artwork between workspaces with a clear account of what stays editable and how animation is preserved.

    Export choices & accessible motion

    Choose a still at the current playhead and define reduced-motion behavior. Evaluate GIF, video, and Lottie against actual delivery needs.

    SVG teamwork & automation

    Discuss comments, shared editing, and AI/MCP access for SVG projects. Design supports team editing; SVG currently uses an exclusive editing lease.

    These are research candidates. Formats and shared editing need compatibility decisions before any delivery commitment.

Proposed direction / Design & shared quality

Make the details
hold up.

New tools belong alongside dependable editing. These gaps remain part of the discussion for the main Design product.

PERFORMANCE

Responsive larger files

Continue reducing canvas, property, and layout latency. The latest cross-platform measurements still exceed the 100 ms interaction target.

DESIGN WORKFLOWS

Finish the finer controls

Improve style organization, rich text, vector construction, masks, and advanced component authoring. Verify consistency, accessibility, and working controls across the workspace.

COMPATIBILITY

More faithful exchange

Improve complex Figma imports and clearly report unsupported features. Explore richer prototypes and additional export formats, including PDF.

RELIABILITY & ACCESS

Confidence in daily use

Broaden keyboard, screen-reader, sleep/reconnect, and real team-installation checks. Public Mac signing and notarization remain separate release work.
