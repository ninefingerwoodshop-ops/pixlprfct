# Repository Map

A directory-by-directory guide to the repo. **Authored code lives in six places: `src/` (Rust engine), `web/` (editor), `server/` (self-host), `app/` + `lib/` + `db/` + `worker/` (Sites/Cloudflare app), `desktop/` (Electron) and `mcp/` (agent server).** Everything else is build tooling, tests, docs, or generated output you should not edit by hand.

## At a glance

| Area | Directory | Language | Size (approx.) |
| --- | --- | --- | --- |
| Document engine | `src/` | Rust → WASM | ~13k lines, 27 modules |
| Editor UI | `web/` | Vanilla ES modules + CSS + HTML | ~250 files, ~3 MB source |
| Sites/Cloudflare app | `app/`, `lib/`, `db/`, `drizzle/`, `worker/`, `components/` | TypeScript / Next (vinext) | small |
| Self-hosted server | `server/` | Node ESM | 17 files |
| Desktop | `desktop/` | Electron (CommonJS) | 16 files |
| MCP server | `mcp/` | Node ESM | 6 files |
| Build & ops scripts | `scripts/` | Node ESM | 44 files |
| Tests | `tests/` | `node:test`, Playwright | ~200 files |
| Docs | `docs/`, root `*.md` | Markdown | ~37 docs |
| Product website | `site/` | Static HTML/CSS/JS | GitHub Pages |

## `src/` — Rust engine

`lib.rs` (~3.9k lines) owns the document type, mutations, history and the `#[wasm_bindgen]` surface. Feature modules: `layout.rs` (auto layout), `grid.rs` (CSS-grid layout), `components.rs`, `variants.rs`, `component_properties.rs`, `slots.rs`, `variables.rs`, `groups.rs`, `paint.rs`, `color_styles.rs`, `text_styles.rs`, `effect_styles.rs`, `guide_styles.rs`, `frame_enclosure.rs`, `layer_drop.rs`, `path_join.rs`, `path_split.rs`, `stroke_tips.rs`, `stroke_alignment.rs`, `arrangement.rs`, `stacking.rs`, `rotation.rs`, `document_order.rs`, `page_background.rs`, `starter_defaults.rs`, `editor_tools.rs`. → [Rust Document Engine](Rust-Document-Engine.md)

## `tests/`

~200 `*.test.mjs` files run by `node --test` (largest groups: grid, layout, prototype, svg, cloud, paint, team, mcp, desktop, component), `tests/browser/*.spec.mjs` for Playwright (editor, daily-workflow, libraries, library-overrides, live-editing, styles, product-site) with macOS snapshot folders, plus `fixtures/` and `helpers/`. → [Testing and Verification](Testing-and-Verification.md)

## Things that look important but aren't (yet)

- `packages/` — empty.
- `examples/d1/` — Sites starter example; excluded from `tsconfig`.
- `components/ui/` and `hooks/use-mobile.ts` — shadcn scaffold from the Sites template; the editor itself does not use React.
- `.local/`, `.agents/`, `.codex/`, `outputs/`, `work/` — local agent/workspace scratch (gitignored).
